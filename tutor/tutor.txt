このチュートリアルは、マウスを使わずにキーボードショートカットだけで
効率的にコードを編集する感覚を身につけるための実践テキストです。

【ルール】
・マウスやトラックパッドには一切触れないでください。
・指示に従って、各レッスン内の「練習用テキスト」を直接編集してください。
・移動は矢印キー、または各レッスンで指示されるショートカットを使います。
・英字を入力するときは、日本語入力を「英数」モードにしておくとスムーズです。
・このファイルは作業用のコピーです。どれだけ壊しても大丈夫です。
  （bin/vscode-tutor を実行するたびに、まっさらな状態に戻ります）

### レッスン 1: 高速カーソル移動

【覚えるキー】
⌥ + ← / → : 単語単位で前後にジャンプ
⌘ + ← / → : 行頭 / 行末に一瞬でジャンプ
⌘ + ↑ / ↓ : ファイルの最上部 / 最下部にジャンプ

【練習 1.1】単語ごとの移動

1. 下の行の先頭にカーソルを置きます。
2. ⌥ を押しながら → を何回か押し、単語の区切りごとにカーソルが跳ぶことを確認してください。
3. 続けて ⌥ + ← で、単語ごとに戻ってください。

[練習]
const userProfileData = fetchCustomerAccountDetails(activeUserId);

【練習 1.2】行頭と行末へのジャンプ

1. 下の行の中央付近にカーソルを置きます（⌥ + → を使うと早いです）。
2. ⌘ + → を押して一瞬で行末に移動し、続けて ⌘ + ← を押して行頭に戻ってください。

[練習]
ここから右端まで一瞬で移動し、再び左端まで一瞬で戻ってください。

【練習 1.3】ファイルの端へのジャンプ（目印: back13）

1. ⌘ + ↓ を押して、ファイルの最下部へジャンプしてください。
   最下部にメッセージが書いてあります。
2. メッセージを読んだら ⌘ + ↑ を押して、ファイルの最上部へジャンプしてください。
3. ここへ戻るには、⌘ + F を押して `back13` と入力し、Enter → Esc の順に押します。
   （カーソルがこの行の「back13」の位置に戻ってきます）

### レッスン 2: 行の削除と挿入

【覚えるキー】
⌘ + ⇧ + K : カーソルがある行を1行丸ごと削除
⌘ + Enter : カーソルの位置に関係なく、直下に新しい行を挿入
⌘ + ⇧ + Enter : カーソルの位置に関係なく、直上に新しい行を挿入

【練習 2.1】不要な行の削除

1. 下の不要な行（REMOVE ME）のどこかにカーソルを置きます（文字を選択する必要はありません）。
2. ⌘ + ⇧ + K を押して、その行を消去してください。

[練習]
Keep this line.
REMOVE ME - この行を ⌘ + ⇧ + K で削除してください
Keep this line too.

【練習 2.2】行の挿入

1. 下の「ステップ1」の行の途中にカーソルを置きます。
2. ⌘ + Enter を押し、下にできた新しい行に「ステップ2」と入力してください。
3. 再び「ステップ1」の行にカーソルを戻し、⌘ + ⇧ + Enter を押して上に「ステップ0」を入力してください。

[練習]
ステップ1

### レッスン 3: 行の並べ替えと複製

【覚えるキー】
⌥ + ↑ / ↓ : 現在の行（または選択行）を上下に移動
⌥ + ⇧ + ↑ / ↓ : 現在の行（または選択行）を上下に複製

【練習 3.1】行の並べ替え

1. 下のリストは順番が崩れています。
2. ⌥ + ↑ または ⌥ + ↓ を使い、1 → 2 → 3 の正しい昇順に並べ替えてください。

[練習]
3. 最後に確認する
1. 最初に入力する
2. 次に検証する

【練習 3.2】行の複製

1. 下の「アイテムA」の行にカーソルを置きます。
2. ⌥ + ⇧ + ↓ を2回押し、3行に複製してください。
3. 複製した行をそれぞれ「アイテムB」「アイテムC」に書き換えてください。

[練習]
アイテムA

### レッスン 4: マルチカーソル（同名単語の一括編集）

【覚えるキー】
⌘ + D : カーソル位置の単語を選択し、押すごとに次の同一単語を追加選択
⌘ + U : 選択しすぎた場合に1つ前の選択状態に戻す
Esc : マルチカーソルを解除

【ポイント】
何も選択していない状態から ⌘ + D を始めると「単語全体が一致するもの」だけが選ばれます。
（例: `name` から始めると `username` は選ばれません）

【練習 4.1】同じ単語の一括置換

1. 下のコードの1行目にある `old_name` にカーソルを合わせます。
2. ⌘ + D を押します（`old_name` が選択されます）。
3. もう一度 ⌘ + D を押します（2行目の `old_name` も選択されます）。
4. もう一度 ⌘ + D を押します（3行目も選択されます）。
5. そのままキーボードで `new_name` と入力してください。全行同時に書き換わります。
6. 入力が終わったら Esc を押してマルチカーソルを解除します。

[練習]
const old_name = "Alice";
console.log(old_name);
return old_name;

### レッスン 5: 縦列マルチカーソル

【覚えるキー】
⌘ + ⌥ + ↓ / ↑ : 真上・真下にカーソルを追加
Esc : マルチカーソルを解除

【練習 5.1】複数行の先頭に一括で文字を挿入

1. 下の「- りんご」の行頭（ハイフンの左側）にカーソルを置きます。
2. ⌘ + ⌥ + ↓ を2回押し、3行の先頭すべてに縦並びでカーソルがある状態を作ります。
3. キーボードで `[x] ` と入力してください。
4. Esc を押して解除します。

[練習]
- りんご
- みかん
- ぶどう

### レッスン 6: ファイル切り替え・コメントアウト・整形

コメントアウトや自動整形は、VS Code が「何の言語か」を分かっているファイルでしか働きません。
このファイル（tutor.txt）はただのテキストなので、レッスン 6 は
JavaScript の練習ファイル practice.js を使います。

【覚えるキー】
⌘ + P : ファイル名で検索して開く（Quick Open）
⌘ + / : 行コメントの切り替え（// の追加・削除）
⌥ + ⇧ + F : ドキュメント全体の自動コード整形

【練習 6.0】ファイルを切り替える

1. ⌘ + P を押します。
2. `practice` と入力して Enter を押し、practice.js を開きます。
3. practice.js に書かれた指示に従って、練習 6.1〜6.3 を行ってください。
4. 終わったら ⌘ + P → `tutor` → Enter でこのファイルに戻り、卒業試験へ進みます。

### 総合卒業試験（タイムアタック目標: 30秒）

マウスを使わず、キーボードだけで以下の【未完成コード】を【目標の姿】に修正してください。

【未完成コード】
function processData() {
  const bad_val = 10;
  console.log("ログ出力（不要）");
  const limit = bad_val * 10;
  // Step 2
  // Step 1
  return bad_val + limit;
}

【やること】

1. 2行目の bad_val にカーソルを置き、⌘ + D を3回押して3箇所を選択し、`good_val` と入力する。
   （押しすぎて下の説明文まで選択されたら ⌘ + U で1つ戻せます）
2. `console.log(...)` の行を ⌘ + ⇧ + K でまるごと削除する。
3. `// Step 1` と `// Step 2` の順序を ⌥ + ↑ で入れ替える。

【目標の姿】
function processData() {
  const good_val = 10;
  const limit = good_val * 10;
  // Step 1
  // Step 2
  return good_val + limit;
}
