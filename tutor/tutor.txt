このチュートリアルは、マウスを使わずにキーボードショートカットだけで
効率的にコードを編集する感覚を身につけるための実践テキストです。

【キー記号の凡例】
⌘ : Command（コマンド）
⌥ : Option（オプション）
⇧ : Shift（シフト）
⌃ : Control（コントロール）
Enter : Return（エンターキー）

【ルール】
・マウスやトラックパッドには一切触れないでください。
・指示に従って、各レッスン内の「練習用テキスト」を直接編集してください。
・移動は矢印キー、または各レッスンで指示されるショートカットを使います。
・英字を入力するときは、日本語入力を「英数」モードにしておくとスムーズです。
・操作を失敗したときは、いつでも ⌘ + Z で元に戻せます。
・このファイルは作業用のコピーです。どれだけ壊しても大丈夫です。
  （bin/vscode-tutor を実行するたびに、まっさらな状態に戻ります）

### レッスン 1: 高速カーソル移動

【覚えるキー】
⌥ + ← / → : 単語単位で前後にジャンプ
⌃ + ⌥ + ← / → : キャメルケース（単語の区切り）単位でジャンプ
⌘ + ← / → : 行頭 / 行末に一瞬でジャンプ
⌘ + ↑ / ↓ : ファイルの最上部 / 最下部にジャンプ
⌃ + - : 直前のカーソル位置に戻る (Go Back)

【練習 1.1】単語ごとの移動

1. 下の行の先頭にカーソルを置きます。
2. ⌥ を押しながら → を何回か押し、単語の区切りごとにカーソルが跳ぶことを確認してください。
3. 続けて ⌥ + ← で、単語ごとに戻ってください。
4. （応用）⌃ + ⌥ + → を押すと、`userProfileData` や `fetchCustomerAccountDetails`
   のようなキャメルケースの単語の途中でもピタッと止まれます！

[練習]
const userProfileData = fetchCustomerAccountDetails(activeUserId);

【練習 1.2】行頭と行末へのジャンプ

1. 下の行の中央付近にカーソルを置きます（⌥ + → を使うと単語ごとに素早く移動できます）。
2. ⌘ + → を押して一瞬で行末に移動し、続けて ⌘ + ← を押して行頭に戻ってください。

[練習]
Jump across these English words to the middle of this line easily.

【練習 1.3】ファイルの端へのジャンプと復帰

1. ⌘ + ↓ を押して、ファイルの最下部へジャンプしてください。
   最下部にメッセージが書いてあります。
2. メッセージを確認したら、⌃ + - (Control + ハイフン) を押してください。
   直前にいたこの練習 1.3 の位置へ一瞬で戻ってきます！
   （VS Code では 10行以上の大きな移動は履歴に記録されるため、⌃ + - で元に戻れます）

### レッスン 2: 行の削除と挿入

【覚えるキー】
⌘ + ⇧ + K : カーソルがある行を1行丸ごと削除
⌘ + Enter : カーソルの位置に関係なく、直下に新しい行を挿入
⌘ + ⇧ + Enter : カーソルの位置に関係なく、直上に新しい行を挿入

【練習 2.1】不要な行の削除

1. 下の不要な行（REMOVE ME）のどこかにカーソルを置きます（文字を選択する必要はありません）。
2. ⌘ + ⇧ + K を押して、その行を消去してください。

[練習]
Keep this line.
REMOVE ME - この行を ⌘ + ⇧ + K で削除してください
Keep this line too.

【練習 2.2】行の挿入

1. 下の「Step 1」の行の途中にカーソルを置きます。
2. ⌘ + Enter を押し、下にできた新しい行に「Step 2」と入力してください。
3. 再び「Step 1」の行にカーソルを戻し、⌘ + ⇧ + Enter を押して上に「Step 0」を入力してください。

[練習]
Step 1

### レッスン 3: 行の並べ替えと複製

【覚えるキー】
⌥ + ↑ / ↓ : 現在の行（または選択行）を上下に移動
⌥ + ⇧ + ↑ / ↓ : 現在の行（または選択行）を上下に複製

【練習 3.1】行の並べ替え

1. 下のリストは順番が崩れています。
2. ⌥ + ↑ または ⌥ + ↓ を使い、1 → 2 → 3 の正しい昇順に並べ替えてください。

[練習]
3. 最後に確認する
1. 最初に入力する
2. 次に検証する

【練習 3.2】行の複製

1. 下の「アイテムA」の行にカーソルを置きます。
2. ⌥ + ⇧ + ↓ を2回押し、3行に複製してください。
3. 複製した行をそれぞれ「アイテムB」「アイテムC」に書き換えてください。

[練習]
アイテムA

### レッスン 4: マルチカーソル（同名単語の一括編集）

【覚えるキー】
⌘ + D : カーソル位置の単語を選択し、押すごとに次の同一単語を追加選択
⌘ + U : 選択しすぎた場合に1つ前の選択状態に戻す
⌘ + K ⌘ + D : 現在の単語をスキップして次の同一単語を選択
⌘ + ⇧ + L : ファイル内の同一単語を一括ですべて選択
Esc : マルチカーソルを解除

【ポイント】
何も選択していない状態から ⌘ + D を始めると「単語全体が一致するもの」だけが選ばれます。
（例: `name` から始めると `username` は選ばれません）

【練習 4.1】同じ単語の一括置換

1. 下のコードの1行目にある `old_name` にカーソルを合わせます。
2. ⌘ + D を押します（`old_name` が選択されます）。
3. もう一度 ⌘ + D を押します（2行目の `old_name` も選択されます）。
4. もう一度 ⌘ + D を押します（3行目も選択されます）。
5. そのままキーボードで `new_name` と入力してください。全行同時に書き換わります。
6. 入力が終わったら Esc を押してマルチカーソルを解除します（カーソルが1つに戻ります）。
   ※もし補完候補などのポップアップが出ている場合は、Esc を2回押してください。

[練習]
const old_name = "Alice";
console.log(old_name);
return old_name;

【練習 4.2】選択の取り消し (⌘ + U) とスキップ (⌘ + K ⌘ + D)

1. 下のコードの1行目の `target` にカーソルを置き、⌘ + D を4回押してすべて選択してください。
2. 4回目で余計なコメントまで選んでしまいました。⌘ + U を1回押して直前の選択を取り消してください。
3. 一度 Esc で解除し、再度1行目の `target` にカーソルを置きます。
4. ⌘ + D を2回押して、1行目と2行目を両方選択します。
5. 続けて ⌘ + K → ⌘ + D の順に押すと、2行目の選択が解除されて3行目へ移動し、
   「1行目と3行目が同時に選ばれた状態（2行目をスキップ）」になることを確認してください。
6. 最後に Esc でマルチカーソルを解除します。

[練習]
const target = 1;
const target = 2; // スキップしたい
const target = 3;
// target (ここまで選ばない)

### レッスン 5: 縦列マルチカーソル

【覚えるキー】
⌘ + ⌥ + ↓ / ↑ : 真上・真下にカーソルを追加
Esc : マルチカーソルを解除

【練習 5.1】複数行に一括で文字を挿入（タスクリストの作成）

1. 下の「- りんご」の「- 」の後ろ（ハイフンとスペースの右側）にカーソルを置きます。
2. ⌘ + ⌥ + ↓ を2回押し、3行の同じ位置に縦並びでカーソルがある状態を作ります。
3. キーボードで `[x] ` と入力してください（各行が「- [x] 果物名」になります）。
4. Esc を押してマルチカーソルを解除します。

[練習]
- りんご
- みかん
- ぶどう

【練習 5.2】長さの違う行の末尾に一括で文字を追加

1. 下の「const apple = 1」の行頭にカーソルを置きます。
2. ⌘ + ⌥ + ↓ を2回押し、3行の行頭にカーソルを置きます。
3. ⌘ + → を押すと、各行の長さが違っていても全員それぞれの行末にジャンプします！
4. そのまま `;` を入力し、Esc を押してマルチカーソルを解除してください。

[練習]
const apple = 1
const banana = 200
const orange = 3000

### レッスン 6: ファイル切り替え・コメントアウト・整形

コメントアウトや自動整形は、VS Code が「何の言語か」を分かっているファイルでしか働きません。
このファイル（tutor.txt）はただのテキストなので、レッスン 6 は
JavaScript の練習ファイル practice.js を使います。

【覚えるキー】
⌘ + P : ファイル名で検索して開く（Quick Open）
⌘ + L : 現在の行を選択（押すごとに下の行へ選択を拡張）
⌘ + / : 行コメントの切り替え（// の追加・削除）
⌥ + ⇧ + F : ドキュメント全体の自動コード整形

【練習 6.0】ファイルを切り替える

1. ⌘ + P を押します。
2. `practice` と入力して Enter を押し、practice.js を開きます。
3. practice.js に書かれた指示に従って、練習 6.1〜6.3 を行ってください。
4. 終わったら ⌘ + P → `tutor` → Enter でこのファイルに戻り、卒業試験へ進みます。

### 総合卒業試験（タイムアタック目標: 30秒）

マウスを使わず、キーボードだけで以下の【未完成コード】を【目標の姿】に修正してください。

【未完成コード】
function processData() {
  const bad_val = 10;
  console.log("ログ出力（不要）");
  const limit = bad_val * 10;
  // Step 2
  // Step 1
  return bad_val + limit;
}

【やること】

1. 2行目の bad_val にカーソルを置き、⌘ + D を3回押して3箇所を選択し、`good_val` と入力する。
   （押しすぎて下の説明文まで選択されたら ⌘ + U で1つ戻せます）
2. 【重要】入力が終わったら、必ず Esc を押してマルチカーソルを解除する！
   （※マルチカーソルのまま次の行削除を行うと、3行まとめて削除されてしまいます）
3. `console.log(...)` の行にカーソルを移動し、⌘ + ⇧ + K でまるごと削除する。
4. `// Step 1` と `// Step 2` の順序を ⌥ + ↑ で入れ替える。

【目標の姿】
function processData() {
  const good_val = 10;
  const limit = good_val * 10;
  // Step 1
  // Step 2
  return good_val + limit;
}
